画面は Node 版サーバが配ります。サーバを起動すると、トークン付きの URL が出ます。

```sh
node packages/server-node/dist/src/main.js -c patchiri.config.json
# 画面: http://127.0.0.1:7357/#token=…
```

この URL をブラウザで開くと、そのままつながります（トークンはアドレス欄から消え、そのタブのあいだだけ覚えます）。サーバの立て方は [Node 版サーバ](/servers/node/)を見てください。

WebForms のアプリに載せた C# 版・VB.NET 版では、載せたページ（例 `Admin/Patchiri.aspx`）を開くと、同じ画面が載せ先のログインのまま出ます（[WebForms に載せる](/servers/webforms/)）。

## 使い方

1. **対象を選ぶ**: 見出しの「対象」で、更新するテーブル（許可リストのターゲット）を選びます。右の欄に、キーの列と更新できる列が出ます。許可リストに表示名（`labels`）があれば、それも出ます。自動で入る列（更新日時など）と、触れる行の範囲があれば、その下に出ます。
2. **業務ルールを読む**（あれば）: 「ファイルを選ぶ」で `patchiri.rules.json` を読みます。このブラウザが覚えておくので、毎回選ばなくて済みます。サーバに置いたルールは「サーバ n 件」と出て、外せません。
3. **貼り付ける**: Excel で見出しの行ごとコピーし、表の A1 を選んで `Ctrl+V`。1 行目が列名（か表示名）で、キーの列と変える列だけでかまいません。右の一覧の「＋見出し」で見出しを入れることもできます。`Ctrl+Z` で戻せます。「Excel を開く」で .xlsx を選ぶと、シートと見出しの行を選んで表に入れられます（見出しの行は自動で当て、列に当たらない「備考」などの列は外せます。ファイルはブラウザの中で読み、どこにも送りません）。
4. **検証して差分を見る**: 誤りのセルは赤くなり、マウスを乗せると理由が出ます。直すと印が消えるので、もう一度押します。通れば「差分」のタブが開き、これが承認資料になります。
5. **確かめて反映する**: 「DB で確かめる」で DB を変えずに確かめ、「反映する」で 1 トランザクションで反映します。メモ（依頼番号など）は反映ログに残ります。

## 保存できるもの

| ボタン | 中身 |
| --- | --- |
| 差分 CSV | 行ごとの状態と、列ごとの前後の値（承認資料） |
| 問題の一覧 CSV | エラーと警告のセルと理由 |
| 読み替えの一覧 CSV | Excel の表示の形から読み替えたセル |
| 反映計画 plan.json | CLI の `patchiri apply` でも反映できる計画 |
| 実行する SQL / 実行した SQL | 値を埋め込んだ、人が読める SQL |
| 戻し SQL | 今の値が patchiri で入れた値のままの行だけ戻す SQL |
| 結果 JSON | 反映の結果（反映した人、時刻、行数、SQL） |

## 表の印

| 印 | 意味 |
| --- | --- |
| 赤いセル | エラー。直すまで差分を作らない |
| 下に黄色の線 | 警告（前後の空白、変動が大きいなど）。差分は作る |
| 点線の下線 | Excel の表示の形から読み替えたセル。マウスを乗せると読んだ値が出る |
| 青いセル | 差分で変わるセル。マウスを乗せると DB の今の値が出る |
| 黄色いキー | DB にそのキーの行がない |
| 赤いキー | 反映のときに、差分を取った後で DB が変わっていた行 |

タイトル、色、メモ（依頼番号など）の必須、「Excel を開く」、足す CSS は、サーバの設定ファイルの `screen` で変えられます（[画面の設定](/usage/config/#画面の設定)）。

## ほかの React アプリに埋め込む

画面は React の部品（`PatchiriApp`）としても使えます。つなぐ先（`PatchiriClient`）を渡せば、Node 版サーバ以外にもつなげます。タイトル、対象の固定、色、メモの必須、文言、反映の前後の口（`onBeforeApply` など）を props で変えられ、見た目を自前で作るなら `usePatchiri`（流れだけを持つフック）と `DiffGrid`（差分の表）を使います。詳しくは [packages/web の README](https://github.com/ishibashi0112/patchiri/tree/main/packages/web) を見てください。
