---
title: 画面で使う
description: 表に貼り付けて、検証・差分・反映をブラウザで行う
---

画面は Node 版サーバが配ります。サーバを起動すると、トークン付きの URL が出ます。

```sh
node packages/server-node/dist/src/main.js -c patchiri.config.json
# 画面: http://127.0.0.1:7357/#token=…
```

この URL をブラウザで開くと、そのままつながります（トークンはアドレス欄から消え、そのタブのあいだだけ覚えます）。サーバの立て方は [Node 版サーバ](/servers/node/)を見てください。

## 使い方

1. **対象を選ぶ**: 見出しの「対象」で、更新するテーブル（許可リストのターゲット）を選びます。右の欄に、キーの列と更新できる列が出ます。
2. **業務ルールを読む**（あれば）: 「ファイルを選ぶ」で `patchiri.rules.json` を読みます。このブラウザが覚えておくので、毎回選ばなくて済みます。
3. **貼り付ける**: Excel で見出しの行ごとコピーし、表の A1 を選んで `Ctrl+V`。1 行目が列名で、キーの列と変える列だけでかまいません。右の一覧の「＋見出し」で列名を入れることもできます。`Ctrl+Z` で戻せます。
4. **検証して差分を見る**: 誤りのセルは赤くなり、マウスを乗せると理由が出ます。直すと印が消えるので、もう一度押します。通れば「差分」のタブが開き、これが承認資料になります。
5. **確かめて反映する**: 「DB で確かめる」で DB を変えずに確かめ、「反映する」で 1 トランザクションで反映します。メモ（依頼番号など）は反映ログに残ります。

## 保存できるもの

| ボタン | 中身 |
| --- | --- |
| 差分 CSV | 行ごとの状態と、列ごとの前後の値（承認資料） |
| 問題の一覧 CSV | エラーと警告のセルと理由 |
| 読み替えの一覧 CSV | Excel の表示の形から読み替えたセル |
| 反映計画 plan.json | CLI の `patchiri apply` でも反映できる計画 |
| 実行する SQL / 実行した SQL | 値を埋め込んだ、人が読める SQL |
| 戻し SQL | 今の値が patchiri で入れた値のままの行だけ戻す SQL |
| 結果 JSON | 反映の結果（反映した人、時刻、行数、SQL） |

## 表の印

| 印 | 意味 |
| --- | --- |
| 赤いセル | エラー。直すまで差分を作らない |
| 下に黄色の線 | 警告（前後の空白、変動が大きいなど）。差分は作る |
| 点線の下線 | Excel の表示の形から読み替えたセル。マウスを乗せると読んだ値が出る |
| 青いセル | 差分で変わるセル。マウスを乗せると DB の今の値が出る |
| 黄色いキー | DB にそのキーの行がない |
| 赤いキー | 反映のときに、差分を取った後で DB が変わっていた行 |

## ほかの React アプリに埋め込む

画面は React の部品（`PatchiriApp`）としても使えます。つなぐ先（`PatchiriClient`）を渡せば、WebForms の WebMethod など、Node 版サーバ以外にもつなげます。詳しくは [packages/web の README](https://github.com/ishibashi0112/patchiri/tree/main/packages/web) を見てください。
