<CardGrid>
  <Card title="貼って、検証する" icon="document">
    Excel から表に貼るか、Excel / CSV を取り込みます。DB の定義（型、桁、NOT NULL、外部キー）と業務ルールで全部のセルを確かめ、誤りのセルを示します。`2024/4/1` や `¥1,200` のような Excel の表示のままの値も読めます。
  </Card>
  <Card title="差分が承認資料になる" icon="list-format">
    今の DB の値と並べて「変わる」「同じ」「キーなし」に分けます。差分の CSV と反映計画をそのまま承認に回せます。
  </Card>
  <Card title="止まる反映、戻せる記録" icon="approve-check">
    反映は 1 トランザクション。差分を取った後で DB が変わっていたら、何も反映せずに止まります。実行した SQL と、上書きしない戻し SQL が残ります。
  </Card>
  <Card title="SQL は人が書かない" icon="setting">
    サーバは許可リストのテーブルと列だけを扱い、パラメータ付きの UPDATE を自分で組み立てます。反映の API に SQL を渡す口はありません。
  </Card>
</CardGrid>
